# My Password Vault

一個純單檔、零外部依賴、**純記憶體運作**的離線網頁版密碼管理器。所有資料僅暫存於當前瀏覽器記憶體中，不會寫入 `localStorage`、`sessionStorage`、Cookie 或任何後端伺服器，關閉或重新整理分頁即清空，適合搭配本機 `TXT` 檔案進行匯入與匯出管理。

## 功能特色

* **純記憶體運作**：不上傳雲端、不寫入瀏覽器儲存空間，重新整理或關閉分頁後自動清除工作區資料。
* **TXT 匯入與匯出**：支援透過「匯入 TXT」按鈕或**拖曳 `.txt` 檔案**至列表卡片匯入；編輯後可一鍵匯出為 `passwords.txt`。
* **匯入衝突處理**：當列表已有資料時再次匯入，可選擇「加入目前資料」或「覆蓋目前資料」；若格式不符會阻擋匯入並列出詳細錯誤行號。
* **即時搜尋與快速操作**：支援依「名稱」或「帳號」即時搜尋，提供帳號/密碼一鍵複製、密碼顯示/隱藏切換、新增、編輯與刪除。
* **下載獨立單檔 HTML**：可隨時下載一份重設為初始空白狀態的獨立 `MyPasswordVault.html`，方便離線保存或雙擊開啟。
* **響應式介面**：支援桌面與手機版面自適應顯示。
* **新增帳號密碼**：支援在網頁中直些新增，以便之後匯出.txt檔案。

## TXT 檔案格式規範

每筆資料固定為 **3 行**，多筆資料之間以**連續兩個以上的減號**（例如 `---` 或 `----------`）分隔：

* **第 1 行**：名稱（必填）
* **第 2 行**：帳號（可留空，但需保留該行）
* **第 3 行**：密碼（必填）

### 格式範例

```text
CMD
AABBCC
123123
---
Google
example@gmail.com
abc123456
----------
某個沒有帳號的服務

mypassword123
